The design system is written to be read by coding agents as well as by people. The rule is the same for both: **before implementing UI, check the Synapse Design System.**

## Where to read

- [`/llms.txt`](/llms.txt) lists the documentation, and [`/llms-full.txt`](/llms-full.txt) gives all of it as text.
- [`/tokens.json`](/tokens.json) gives every token and its values.
- [`AGENTS.md`](https://github.com/stevenCayla/synapse-design-system/blob/main/AGENTS.md) gives the rules for working in this repository.

## Rules

An agent does not invent a colour, a spacing, a button, a variant or a pattern when a suitable one exists. It uses `--si-*` tokens, never a hard-coded value, and keeps labels out of components.
