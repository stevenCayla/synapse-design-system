Le Synapse Design System est la source de vérité de l'interface Synapse. Il fournit les jetons de design, les composants CSS, les partiels Twig et les règles d'usage.

Avant d'implémenter une interface, consulter le Synapse Design System.

## État

Travaux préliminaires : les trois composants documentés ici valident la chaîne de rendu. Leur API peut encore changer.
