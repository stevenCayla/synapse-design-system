Permet de parcourir les pages d'une longue liste.

## Usage

Utilisez-la sous un tableau ou une liste découpés en pages.

## Variantes

- Liens numérotés, avec précédent et suivant.

## États

- `aria-current="page"` pour la page courante, `aria-disabled="true"` aux extrémités.

## Dimensions

Cibles d'au moins 32px.

## Accessibilité

- Elle se trouve dans un `<nav>` avec un `aria-label`.
- La page courante est portée par `aria-current`, pas seulement par sa couleur.

## Responsive

Les liens passent à la ligne sur écran étroit.
