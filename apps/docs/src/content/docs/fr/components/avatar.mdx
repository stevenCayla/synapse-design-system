Représente une personne ou une organisation.

## Usage

Utilisez-le à côté d'un nom, dans les listes et les en-têtes.

## Variantes

- Initiales, ou image avec `image`.
- Carré arrondi par défaut, **rond** avec `round: true`.

## États

- Statique.

## Dimensions

24px (`sm`), 32px (par défaut), 40px (`lg`), 64px (`xl`).

## Accessibilité

- `name` est lu par les lecteurs d'écran, et les initiales leur sont masquées.
- Si le nom est déjà à côté, il est répété : gardez-le court.

## Responsive

Une taille fixe : il ne se réduit pas dans une ligne.
