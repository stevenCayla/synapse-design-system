Un message sur un état ou le résultat d'une action.

## Usage

Utilisez une alerte pour un message qui concerne toute une page ou une section. Pour une brève confirmation qui disparaît seule, utilisez un [toast](/fr/components/toast/).

## Variantes

- **Tonalités :** par défaut, `success`, `warning`, `danger`, `info`.
- **Note** (`variant: note`) : une remarque dans une page ou un formulaire.
- **Bannière** (`variant: banner`) : un message en haut de page.
- **Icône**, **titre** et contenu riche avec `embed`.

## États

- **Fermable :** `dismiss_label` ajoute un bouton de fermeture, avec le script des comportements.

## Dimensions

Elle prend la largeur de son conteneur.

## Accessibilité

- `role="status"` par défaut. Réservez `role: alert` à ce qui demande une attention immédiate.
- L'icône est décorative : le texte dit l'état.

## Responsive

Le texte passe à la ligne ; la largeur suit le conteneur.
