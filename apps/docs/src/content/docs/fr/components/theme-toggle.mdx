Passe du thème clair au thème sombre.

## Usage

Utilisez-la une seule fois, dans l'en-tête de l'application.

## Variantes

- Un seul bouton icône.

## États

- L'icône suit `data-theme` en CSS, et le libellé dit le thème vers lequel elle bascule.

## Dimensions

Un bouton icône de 36px.

## Accessibilité

- Le libellé change avec l'état, et utilise la langue de l'utilisateur.

## Responsive

Elle garde sa taille.

  <Fragment slot="do">Suivez le système tant que la personne n'a pas choisi.</Fragment>

## API

Partiel `@si/theme-toggle.html.twig` : `to_dark`, `to_light`. JS : `setTheme(theme)`, clé `synapse-theme`. La page demande un petit script dans `<head>` qui pose `data-theme` avant le premier affichage, avec cette clé. Demande le script des comportements : `import '.../js/behaviors.js'`.
