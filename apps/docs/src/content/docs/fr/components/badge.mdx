Une étiquette courte pour un état ou une catégorie.

## Usage

Utilisez un badge pour indiquer un état ou une catégorie à côté de l'élément concerné. C'est le texte qui porte le sens, pas la couleur.

## Variantes

- **Tonalités :** par défaut, `success`, `warning`, `danger`, `info`, `neutral`.
- **Pilule** (`pill: true`) et **point d'état** (`dot: true`).
- **Icône :** `icon`, décorative.

## États

- Un badge est statique. Pour filtrer, utilisez une [puce](/fr/components/chip/).

## Dimensions

Texte de 12px sur une ligne d'environ 22px.

## Accessibilité

- Le texte dit l'état : jamais la couleur seule.
- Le texte est échappé, et chaque tonalité atteint 4,5:1 sur son propre fond.

## Responsive

Il reste sur une ligne et suit le texte autour de lui.

## API

Partiel `@si/badge.html.twig` : `label`, `tone`, `pill`, `dot`, `icon`. L'application associe ses états aux tonalités.
