Le Design System est écrit pour être lu par les agents de code comme par les personnes. La règle est la même pour tous : **avant d'implémenter une interface, consulter le Synapse Medical Design System.**

## Où lire

- [`/llms.txt`](/llms.txt) liste la documentation, et [`/llms-full.txt`](/llms-full.txt) la donne en entier en texte.
- [`/tokens.json`](/tokens.json) donne chaque jeton et ses valeurs.
- [`AGENTS.md`](https://github.com/synapse-medical/synapse-design-system/blob/main/AGENTS.md) donne les règles de travail dans ce dépôt.

## Règles

Un agent n'invente pas une couleur, un espacement, un bouton, une variante ou un pattern si une solution existe. Il utilise les jetons `--si-*`, jamais de valeur en dur, et garde les libellés hors des composants.
