import ScaleTable from '../../../../components/foundations/ScaleTable.astro';

Une ombre indique qu'un élément est posé au-dessus de la page. `sm` pour un léger relief, `md` pour une carte ou un menu surélevé, `lg` pour ce qui flotte, comme une modale. Quand deux valeurs sont affichées, la première vaut pour le thème clair et la seconde pour le sombre.
