Shows or hides secondary content.

## Usage

Use it for details that most people do not need. Several in a row make an accordion.

## Variants

- Closed by default, open with the `open` attribute. The `name` attribute keeps one open in a group.

## States

- Open, closed, hover and `:focus-visible`.

## Dimensions

It fills its container.

## Accessibility

- It is the native `<details>` element: keyboard and screen readers need nothing else.
- Do not hide required information or a form error in it.

## Responsive

The summary wraps on a narrow screen.

## API

No partial and no script. Classes: `si-disclosure`, `si-disclosure__body`.
