Replaces content that is missing or could not load.

## Usage

Use it when a list has nothing to show, when a search finds nothing, or when loading fails. Say why, and what to do.

## Variants

- **Nothing yet:** with an action to start.
- **No result:** `compact`, inside a list.
- **Error:** `tone: danger`, with a way to try again.

## States

- Static. For a wait, use [loading](/components/loading/).

## Dimensions

Centred, with `compact` for less padding in a card or a drawer.

## Accessibility

- Choose the heading level with `level`.
- `role: alert` when it appears as the result of an action.

## Responsive

The text is limited to a readable width.
