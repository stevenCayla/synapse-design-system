A message about a state or the result of an action.

## Usage

Use an alert for a message that concerns a whole page or section. For a short confirmation that leaves on its own, use a [toast](/components/toast/).

## Variants

- **Tones:** default, `success`, `warning`, `danger`, `info`.
- **Note** (`variant: note`): a remark inside a page or a form.
- **Banner** (`variant: banner`): a message at the top of a page.
- **Icon**, **title** and rich content with `embed`.

## States

- **Dismissible:** `dismiss_label` adds a close button, with the behaviours script.

## Dimensions

It takes the width of its container.

## Accessibility

- `role="status"` by default. Use `role: alert` only for what needs immediate attention.
- An icon is decorative: the text says the state.

## Responsive

The text wraps; the width follows the container.
